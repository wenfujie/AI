# 代码库关注点

**分析日期：** 2026-05-25

## 技术债

**CI 测试脚本缺口：**
- 问题：`.github/workflows/test.yml` 执行 `pnpm run test`，但 `package.json` 未定义 `test`。
- 文件：`.github/workflows/test.yml`、`package.json`
- 影响：PR 检查可能持续失败，阻塞发布节奏。
- 修复方向：新增 `test` 脚本并落地最小测试集，或调整 CI 流程去掉该步骤。

**生成文件管理策略未明确：**
- 问题：`auto-imports.d.ts`、`components.d.ts`、`src/typed-router.d.ts` 属于生成文件，但更新策略未在 `README.md` 说明。
- 文件：`auto-imports.d.ts`、`components.d.ts`、`src/typed-router.d.ts`、`README.md`
- 影响：团队成员可能在冲突时误改生成文件。
- 修复方向：在文档中明确“何时生成、何时提交、冲突如何处理”。

## 已知缺陷

**路由兜底页面过于简化：**
- 症状：404 页面仅显示 `Not Found`，缺少导航与恢复动作。
- 文件：`src/pages/[...all].vue`
- 触发：用户访问不存在路径。
- 临时方案：手动返回首页。

## 安全考量

**前端安全头依赖平台默认：**
- 风险：未在仓库内看到 CSP、HSTS 等显式策略配置。
- 文件：`index.html`、`netlify.toml`
- 当前缓解：无代码层配置，依赖托管平台默认策略。
- 建议：在部署平台增加 CSP 与安全头策略，并将关键策略记录到文档。

**外链跳转边界控制有限：**
- 风险：`target="_blank"` 外链虽有 `rel="noreferrer"`，但仍需统一外链审计流程。
- 文件：`src/components/TheFooter.vue`
- 当前缓解：已使用 `rel="noreferrer"`。
- 建议：建立统一外链白名单规范。

## 性能瓶颈

**首屏脚本初始化集中在入口：**
- 问题：主题判断脚本与应用初始化都在首屏阶段执行。
- 文件：`index.html`、`src/main.ts`
- 原因：项目当前是最小模板，尚无懒加载优化策略。
- 优化路径：按路由拆分大模块，引入关键路径性能监控。

## 脆弱区域

**自动生成路由类型链路：**
- 文件：`src/typed-router.d.ts`、`vite.config.ts`
- 脆弱原因：若插件配置改变或文件未重新生成，类型与真实路由可能漂移。
- 安全修改：变更路由插件后立即执行类型检查并提交生成文件。
- 测试覆盖：当前无自动化测试保护该链路。

## 可扩展性限制

**缺少服务层抽象：**
- 当前容量：适合静态页面与轻逻辑交互。
- 限制：当 API 集成增多时，页面层直接处理副作用会快速失控。
- 扩展路径：引入 `src/services/` 与错误封装层，再逐步补集成测试。

## 风险依赖

**模板生态快速迭代：**
- 依赖：`unplugin-*`、`unocss`、`vite`（版本由 `pnpm-workspace.yaml` catalog 管理）
- 风险：升级时可能出现生成行为或插件兼容性变化。
- 影响：构建失败或自动导入行为异常。
- 迁移计划：升级前固定版本、先跑 `typecheck + lint + build` 再合并。

## 关键能力缺失

**缺少业务测试基线：**
- 问题：未发现单元测试与集成测试文件。
- 阻塞：后续功能迭代缺少回归保护网。

**缺少错误监控集成：**
- 问题：无错误追踪服务接入。
- 阻塞：线上问题只能依赖人工复现与平台日志。

## 测试覆盖缺口

**主题切换逻辑未覆盖：**
- 未测试内容：`isDark` 与 `toggleDark` 的行为正确性。
- 文件：`src/composables/dark.ts`
- 风险：主题状态回归无法被 CI 捕获。
- 优先级：High

**路由兜底行为未覆盖：**
- 未测试内容：未知路径是否稳定落到 `src/pages/[...all].vue`。
- 文件：`src/pages/[...all].vue`、`src/main.ts`
- 风险：路由配置变更后可能出现白屏。
- 优先级：Medium
